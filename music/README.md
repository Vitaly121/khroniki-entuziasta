# Музыка залов

Сюда кладутся звуковые файлы для залов музея. Без файлов музей работает как раньше — в тишине с шумами залов.

**Форматы:** mp3, m4a, ogg или wav. Лучше всего mp3 или m4a 128–160 кбит/с; один файл — не больше 5–8 МБ (страница сайта статическая, файл скачивается целиком). Имя файла — без косых черт и знаков `? # % " < > : * |`.

**Как добавить трек**
1. Положите файл в эту папку `music/`.
2. Допишите его в `tracks.json`: `{"file": "имя-файла.mp3", "title": "Название", "artist": "Исполнитель"}`. Трек, которого нет в этом списке, музей не играет.
3. Разложите треки по залам в `playlists.json`: для каждого зала — `"tracks"` (порядок воспроизведения), `"volume"` от 0 до 1, `"shuffle"` (вперемешку) и `"loop"` (по кругу). Ключи залов: `kv` Квартиры, `pr` Предметы, `id` Идеи, `sv` Святилище, `dv` Двойники, `ot` Отец, `se` Семья, `n` N, `kl` Клуб энтузиастов, `kr` Красота, `hb` База Героев.

**Панель «Музыка залов».** Откройте музей с `?author=1` в адресе (например, `…/?author=1#floor-m1`) — в музее появится кнопка «музыка залов». В ней можно добавить трек из списка, убрать, переставить, задать громкость, «вперемешку» и «по кругу», послушать. «Применить» меняет музыку только у вас (в этом браузере). Чтобы её услышали все, нажмите «Скачать playlists.json» или «Скопировать» и замените этим текстом файл `music/playlists.json` в репозитории.

Сейчас здесь лежат три тихие заглушки `placeholder-*.wav` («Заглушка 1–3») для проверки; их можно удалить вместе со строками в `tracks.json` и `playlists.json`.

**Права.** Публикуйте только музыку, на которую у вас есть права (своя, по лицензии, разрешающей размещение на сайте, или с разрешения правообладателя): файлы из этой папки доступны любому посетителю.
