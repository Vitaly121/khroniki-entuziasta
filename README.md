# Хроники энтузиаста

Трансмедийный сайт к роману: карта смыслов, дневники, переписки, музей вещей, живые копии.

Статический сайт (HTML + JS), публикуется через GitHub Pages из ветки `main`, корень репозитория.

На GitHub Pages живые ответы копий, общий прогресс, следы читателей и «музей вместе» не работают: они требуют среды Claude. Копии отвечают заготовками, прогресс хранится в браузере. Полная версия — в Claude.
